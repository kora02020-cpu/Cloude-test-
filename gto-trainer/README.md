# GTO Preflop Trainer

ブラウザだけで動くプリフロップGTO学習ツール（6-max / 100bb）。`index.html` を開くだけで使えます。

## 機能
- **レンジ表**: 13×13グリッドでレイズ/コール/フォールド頻度を表示（混合戦略は色の割合で表示）
- **トレーナー**: ランダムなハンドで判断を出題し、GTO頻度と比較して採点（キー 1/2/3 で回答、Space で次へ）
- **エクイティ計算**: ハンド vs ハンド / レンジ / シナリオレンジのモンテカルロ計算（ボード指定可）

## 構成
- `js/ranges.js` – レンジ表記パーサとシナリオデータ（ここを編集するとレンジを変更できます）
- `js/evaluator.js` – 7枚ハンド評価器とエクイティ計算
- `js/app.js` – UI

レンジは一般的なGTO傾向を元にした学習用の近似値で、ソルバー出力ではありません。
