# GTO Preflop Trainer

ブラウザだけで動くプリフロップGTO学習ツール（6-max / 100bb）。`index.html` を開くだけで使えます。

## 機能
- **レンジ表**: 13×13グリッドでレイズ/コール/フォールド頻度を表示（混合戦略は色の割合で表示）
- **トレーナー**: ランダムなハンドで判断を出題し、GTO頻度と比較して採点（キー 1/2/3 で回答、Space で次へ）
- **ハンド練習**: プリフロップからショーダウンまで1ハンドを通して練習。フロップ以降は相手のベットに対してコール/フォールドを答え、
  相手のベットレンジに対するエクイティとポットオッズで正解とEVを判定（相手は一定のモデルで動き、行動に応じてレンジが絞られます）
- **エクイティ計算**: ハンド vs ハンド / レンジ / シナリオレンジのモンテカルロ計算（ボード指定可）

## シナリオ
- オープン (RFI): UTG / HJ / CO / BTN / SB
- オープンに対する対応 (3ベット/コール/フォールド): BTN vs CO, SB vs BTN, BB vs BTN, BB vs SB
- 3ベットに対する対応 (4ベット/コール/フォールド): UTG vs BTN, CO vs BTN, BTN vs BB, SB vs BB
- 4ベットに対する対応 (5ベット/コール/フォールド): BTN vs CO, SB vs BTN, BB vs BTN
- プッシュ/フォールド (ナッシュ均衡を計算): SB オールイン or フォールド / BB vs SB オールイン（ヘッズアップ, 2〜25bb）

### プッシュ/フォールドの計算方法
`js/pushfold.js` が、169×169 のオールインエクイティ表（`js/equity-data.js`）とカードの重なりを考慮したコンボ数を使い、
仮想プレイ（fictitious play）でナッシュ均衡を求めます。スタックを変えるとその場で計算し直します（1回あたり約0.3秒）。
画面には可搾取度（均衡からのずれ, mbb/ハンド）も表示されます。エクイティ表は `tools/gen-equity.js` で再生成できます。

3ベット・4ベットに直面するシナリオでは、前のアクションでそのスポットに到達するハンド（`prior` で指定したシナリオのレイズ頻度）だけが出題・集計されます。

## 構成
- `js/ranges.js` – レンジ表記パーサとシナリオデータ（ここを編集するとレンジを変更できます）
- `js/evaluator.js` – 7枚ハンド評価器とエクイティ計算
- `js/pushfold.js` – プッシュ/フォールドのナッシュ均衡ソルバー
- `js/equity-data.js` – 169×169 プリフロップ・オールインエクイティ表
- `js/handplay.js` – ハンド練習（フロップ〜ショーダウン）
- `js/app.js` – UI

プッシュ/フォールド以外のレンジは一般的なGTO傾向を元にした学習用の近似値で、ソルバー出力ではありません。
