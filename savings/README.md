# コツコツ印帳

行動科学・脳科学の知見を組み込んだ、習慣化重視の貯金アプリです。
ビルド不要。`index.html` をブラウザで開くだけで動きます（データは端末のブラウザ内に保存）。

## 組み込んだ仕組み

| 仕組み | 根拠 | アプリでの形 |
| --- | --- | --- |
| 実行意図 (if-then) | Gollwitzer | 「〇〇したら、¥〇〇を貯金する」を最初に決める |
| 小さく始める・習慣の積み重ね | BJ Fogg | 既存の習慣をきっかけに1日¥100から |
| 予測できない報酬 (ドーパミン) | 報酬予測誤差 | 印を押すたびにランダムなごほうび、10%で「金の印」 |
| 損失回避 | Kahneman & Tversky | 連続記録カウンター |
| どうにでもなれ効果の防止 | — | 7日連続ごとに「おやすみ券」(最大2枚) |
| 授かり効果 | Nunes & Drèze | 印帳カードは最初から2マス押されている |
| 目標勾配効果 | Kivetz | 進捗バーと「あと¥〇〇」 |
| 未来の自分 | Hershfield | 1/5/10年後の予測額と、1年後の自分へのメッセージ |
| Save More Tomorrow | Thaler & Benartzi | 2週間続くと「来週から+10%」を提案 |
| フレッシュスタート効果 | Dai, Milkman & Riis | 月曜・月初・元日のバナー |
| 習慣化までの目安 | Lally et al. (2010) | 66日メーター |
| 仕組み化 | デフォルト効果 | 自動積立ルール（銀行の自動積立と同じ内容を自動記録） |

ほかに「我慢貯金」「おつり貯金」「100マス貯金」、レベルと肩書き、通帳風の履歴、バックアップ（コピー＆貼り付け）があります。

> お金そのものを動かすことはできません。実際の「自動で貯まる」は、銀行の自動積立や給料日の先取り振替で設定してください。このアプリはその習慣を続けるための記録と動機づけを担当します。

## スマホ連携

| 機能 | iPhone | Android |
| --- | --- | --- |
| ホーム画面に追加（全画面・オフライン動作） | Safari →「共有」→「ホーム画面に追加」 | Chrome →「アプリをインストール」 |
| アイコン長押しのショートカット（印を押す／我慢した／おつり） | — | ○ |
| アイコンの未チェックバッジ | ○（iOS 16.4以降、追加後） | 一部の端末で○ |
| 毎日のリマインダー | カレンダー登録（.ics）＋ショートカットのオートメーション | Googleカレンダー登録、または通知（インストール後） |
| データ移行 | バックアップファイルの書き出し／読み込み | 同左 |
| 進捗のシェア | 共有シート（LINEなど） | 同左 |

`?action=checkin` / `?action=skip` / `?action=roundup` を付けてURLを開くと、該当の画面が直接開きます。通知やカレンダー、iPhoneのショートカットからはこのURLを使います。

### 公開（HTTPSが必要）

ホーム画面に追加して使うには、HTTPSで公開する必要があります。`.github/workflows/pages.yml` で `savings/` を GitHub Pages に公開できます。

1. GitHub の Settings → Pages → Source を「GitHub Actions」にする
2. `main` ブランチにマージする（または Actions タブから手動実行）

非公開リポジトリで GitHub Pages を使うには有料プランが必要です。無料で済ませたい場合は、リポジトリを公開にするか、Netlify や Cloudflare Pages に `savings/` フォルダを置いてください。
